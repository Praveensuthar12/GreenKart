# 🛒 GreenCart – Grocery E-Commerce Platform

GreenCart is a full-stack grocery e-commerce web application built using the **MERN Stack**.  
The platform allows users to browse grocery products, manage their shopping cart, add delivery addresses, place orders, and make online payments.

The project also includes a **new modern and responsive UI** designed to provide a better user experience across desktop, tablet, and mobile devices.
